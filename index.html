This week in AI

Claude Code shipped three releases this week. The notable changes are skills delivered from MCP servers (in beta), built-in charts through the easel mod, and wider support for clients running Claude through a cloud provider. Google released Gemini 4 Neon and made Genie 4 available.

For a consultant, the OpenAI clips on connecting a calendar and asking ChatGPT to reschedule are the quickest thing to show a client. The Codex SVG and 3D demo shows what editing in plain language looks like, and Matt Wolfe's weekly recap is a one-video catch-up on GPT-6.2 and Gemini 4 Neon.

To try something this afternoon, AFFiNE and Twenty are worth a look if clients ask about alternatives to Notion or Salesforce. Stitch skills and Firecrawl need a developer's help. Google's opt-in Personal Intelligence for Search is a privacy question clients may raise.

New models and tools

  • Claude Code 2.1.332 adds skills from MCP servers in beta

    MCP servers can now supply skills, shown as server:skill in the slash menu. A new hook can refuse inline shell commands. Beta, so test first.

    Claude Code releases · 10h

  • Claude Code 2.1.330 adds built-in charts and enterprise admin sign-in

    A built-in mod called easel draws charts on request on Pro, Max and some team plans, macOS and Linux only. Org sign-in applies admin settings.
