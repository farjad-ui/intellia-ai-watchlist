This week in AI

Uber is rolling ChatGPT Work out to more than 30,000 employees after a 1,000-person pilot, and OpenAI announced a Decisions API for fast, low-cost decisions inside apps. Anthropic donated the Agent Skills standard to the Agentic AI Foundation, and Claude Code 2.1.309 fixed several sandbox gaps.

For a consultant, the Uber story is the useful reference this week: a named company moving past engineering to company-wide use, which is the question clients ask when they plan a rollout. The Agent Skills news means skills built for one tool are less likely to be locked in, since more than 70 platforms support the standard.

If you want to try something, Matt Wolfe's short video on Claude's Motion and Dashboards features shows two things you can do from a prompt. Genoffice is a free office suite that lets Claude Code create real Word, Excel and PowerPoint files. Both are afternoon-sized.

Expect questions about ChatGPT ads. OpenAI published how its ad stack keeps ads separate from answers, which is the point retail and marketing clients will press on.
