This week in AI

OpenAI and Oracle are widening their partnership to bring Oracle's business apps and agents into ChatGPT, and Uber is rolling ChatGPT Work out to more than 30,000 staff. Anthropic also announced a 40% discount on Claude for government partners through GSA, and Claude Code 2.1.312 is out.

Codex case studies dominate the video list. Shopify's CTO, HashiCorp's Mitchell Hashimoto and Sotira each show a different way to use it, including one speaker who says not being technical is no reason not to build. They are easy to borrow when a client asks what people actually do with agents.

For legal and professional services clients, the AT&T and Cooley clips share one message: AI does the groundwork and people stay responsible for the answer. Matt Wolfe also tests Google's new Gemini 4 Argon with five prompts, a quick way to see what it can do.

Anthropic donated the Agent Skills standard to the Agentic AI Foundation, and more than 70 platforms already support it. The tools this week are mostly skills and desktop apps: Hallmark and Impeccable for design, Claude SEO for audits, Call.md for meetings.

One caution: a Claude Code user reports service errors using up their paid limits. It is a single account, but worth knowing if your team relies on Claude Code every day.

Tools and skills you can use

  • Hallmark is an anti-AI-slop design skill for coding agents

    Works with Claude Code, Cursor and Codex to keep generated designs from looking generic. Install it into your agent to try.

  • Impeccable gives your coding agent a design vocabulary

    Commands like polish, bolder, critique and audit let you steer and review designs, and catch generic AI output before it ships. Needs a coding agent.

  • Claude SEO adds 26 sub-skills for SEO audits in Claude Code

    Covers technical SEO, schema, local and e-commerce SEO, and PDF or Excel reports. Useful for web clients; optional extensions add live data.

    GitHub trending · 1m

  • Call.md records and analyses meetings with real-time AI

    Gives agents live context from calls, from prep to follow-up. Test on an internal call first; setup effort is not stated.

    GitHub trending · 1m

  • VoiceStudio runs voice cloning and dubbing fully on your own machine

    Open-source tool covering transcription, dictation, video dubbing and audiobooks in 646 languages. Handy for client content, though voice cloning needs consent.

  • Openbot runs persistent AI teammates in a local desktop app
