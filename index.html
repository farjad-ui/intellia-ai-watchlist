This week in AI

Claude Code shipped three releases this week. Version 2.1.332 lets MCP servers offer skills, 2.1.331 adds Code Mode on Bedrock, Google Cloud and Foundry, and 2.1.330 adds a built-in mod that draws charts on request.

For a consultant, the Bedrock and Foundry support matters most when a client must keep AI inside its own cloud. Google also let users connect Wallet, Drive and Gemini to Search, so expect privacy questions about it.

On the tools side, Firecrawl, AFFiNE and AutoClip are the easiest to point a client at, though Firecrawl needs an engineer. The Watch section has short ChatGPT clips you can try in a minute, and a Fireship breakdown of Gemini 4 Neon.

New models and tools

  • Claude Code 2.1.332 adds skills from MCP servers in beta

    Skills offered by connected MCP servers now appear in the / menu as server:skill, plus a new hook that can block inline shell commands.

    Claude Code releases · 2d

  • Claude Code 2.1.331 supports Code Mode on Bedrock, Google Cloud and Foundry

    Terminal sessions on Amazon Bedrock, Google Cloud and Microsoft Foundry now get Code Mode. Relevant for clients who must run Claude through their own cloud.

    Claude Code releases · 3d

  • Claude Code 2.1.330 adds easel, a built-in mod that draws charts

    Claude Code can now draw charts on request and under MCP metrics results, on Pro, Max and some Team plans on macOS and Linux.

  • Google Search can use Wallet, Drive and Gemini data in AI Mode

    Users can opt in to connect Google Wallet, Drive and the Gemini app so Search answers are more personal. Clients may ask about privacy.
